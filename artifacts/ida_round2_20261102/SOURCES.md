# Third-party sources and release scope

## Data sources and redistribution boundaries

Third-party source texts, filled demonstrations, query paragraphs, retrieved passages, real case files, annotation surface strings, and cached responses are omitted. Source text being readable online is not treated as a blanket redistribution permission. The public candidate also omits author contact/identity pages, private paths, credentials, server-operation records, and internal revision/audit histories.

- CMNEE: the [author repository](https://github.com/Mzzzhu/CMNEE) links to ModelScope. The [official ModelScope metadata](https://modelscope.cn/api/v1/datasets/mzzzhu/CMNEE) reported `Apache License 2.0` when checked on 2026-11-02. Obtain the dataset from the original provider. Any later redistribution of that material must satisfy the upstream license, notices, and modification requirements. No CMNEE source text is included here.
- CLUENER2020: obtain the material from the [official repository](https://github.com/CLUEbenchmark/CLUENER2020). The repository README traces the source to THUCTC/Sina News RSS. An explicit original-text redistribution license was not verified in this audit; this package does not assign a new license to those texts.
- Baidu Baike: [the official user agreement](https://wapbaike.baidu.com/item/%E7%99%BE%E5%BA%A6%E7%99%BE%E7%A7%91%E7%94%A8%E6%88%B7%E5%8D%8F%E8%AE%AE/22165389), under its rights provisions, distinguishes authors' rights and authorization for use. Source links or attribution do not by themselves establish all necessary redistribution permissions. No Baike paragraphs are included here.
- KPPatent-ZH: the [upstream dataset-and-code repository](https://github.com/tanggongbo/KPPatent-ZH) carries an [MIT license](https://github.com/tanggongbo/KPPatent-ZH/blob/03881440c311158ba710bb55fcabe66b89182730/LICENSE). The source configuration pins revision `03881440c311158ba710bb55fcabe66b89182730`; the license SHA256 was checked against that revision and matches the recorded hash. Preserve the upstream copyright and permission notice when redistributing covered material. Patent-source raw passages remain omitted from this aggregate-only increment.

Third-party datasets and model weights must be acquired separately under the applicable upstream terms. This increment alone cannot reconstruct the original source corpus or independently rerun the complete model experiment. No new repository-wide license has been imposed on third-party works or on the original project by preparing this directory.


The 73-entry versioned project glossary preserves the source fields in the existing project resource, including [QAonMilitaryKG](https://github.com/liuhuanyong/QAonMilitaryKG) and project seed entries. It is not a release of the complete third-party knowledge graph; its provenance does not impose a new license on the upstream resource.
