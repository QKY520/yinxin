\section{EXPERIMENTAL SETUP}

\subsection{Frozen Evaluation Blocks}

Domain results use all 170 frozen test passages at $K=5$ and seeds 42, 43,
and 44. The primary extractor is
\modelname{Qwen2.5-7B-Instruct} \cite{qwen2024qwen25}, served locally in FP16
through vLLM. Four configurations across three seeds produce 12 domain NER run
units, each with 170 per-query traces and no NER parse failures.

The CLUENER block applies the same A/B/C/D, $K=5$, three-seed design to all
1,343 labeled official development rows, producing 12 further NER run units.
Its fixed parser records 138 final no-prediction outcomes among 16,116
query-cell rows (0.856292\%), below the prespecified 5\% stop threshold. Results
are aggregated within each dataset; the two schemas are never pooled.

\subsection{Controlled Comparisons}

The seed selects A's fixed-random demonstrations and is recorded in generation
requests. B uses deterministic kNN retrieval; C and D replay B's demonstration
identifiers, and D replays frozen RAG passage identifiers. Resource versions,
prompt order, generation settings, and scoring remain fixed within each chain.
With temperature 0.0 and exact-hash caching, B/C/D are deterministic or nearly
so. We report means and sample standard deviations as descriptive run
variation, not independent data-sample uncertainty, and perform no significance
test.

All 24 three-seed units are NER-only. A separate seed-42 Stage-R audit reuses
the four locked domain Stage-N outputs to assess relation extraction without
altering the NER aggregate. Versioned configurations, prompts, responses,
caches, retries, parser outcomes, and per-query predictions remain traceable.
The dependency lock includes vLLM 0.8.5.post1, Transformers 4.51.3,
sentence-transformers 5.6.0, and PyTorch 2.6.0.
