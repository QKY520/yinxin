\section{METHOD}

\subsection{Evidence-Controlled Extraction}

EC-FSIE organizes low-label extraction as an evidence-and-execution contract.
For query $x$ and schema $S$, the prompt receives retrieved demonstrations
$\mathcal{D}_K(x)$, matched glossary entries $\mathcal{G}(x)$, and reranked
passages $\mathcal{R}(x)$. The execution layer $\mathcal{A}$ parses and records
the prediction:
\[
\hat{Y},\tau = \mathcal{A}\!\left(f_{\theta}\!\left(
P\!\left(S,\mathcal{D}_K(x),\mathcal{G}(x),\mathcal{R}(x),x\right)
\right)\right),
\]
where $P$ fixes prompt order, $f_{\theta}$ is the locked local extractor, and
$\tau$ stores request, cache, retry, parser, and output traces. Each evidence
channel has frozen provenance, bounded injection, leakage-safe construction,
and deterministic replay. The A/B/C/D sequence in Table~\ref{tab:configs}
changes one channel at a time.

\subsection{Structured Generation and Replay}

The NER prompt orders the task definition, entity schema, optional glossary,
optional RAG passages, $K$ demonstrations, and query. The extractor must return
a JSON entity list. SHA256 hashes of the complete prompt and generation
settings key the cache. The parser removes code fences, attempts JSON parsing,
and retries once with a legal-JSON reminder; a second failure becomes an empty
prediction while the raw response remains in the trace. Runs use temperature
0.0, top-$p$ 1.0, a 768-token output limit, and a recorded seed.

In A, the seed selects one fixed-random $K$-example set from support. In B,
BGE-M3 \cite{chen2024m3} embeds support and query texts, and normalized
inner-product search retrieves the $K$ nearest examples. C and D replay B's
example identifiers, isolating the glossary and RAG changes.

For equipment text, the query matcher injects at most 20 glossary entries.
RAG divides the leakage-screened public corpus into overlapping chunks,
retrieves 20 candidates with BGE-M3 and FAISS, reranks them with
\modelname{bge-reranker-v2-m3}, and injects the top three. CLUENER uses the
same interfaces with its own support bank, lexicon, and frozen top-three replay.
Embedding and reranking follow the locked CPU path.
