\section{DATASET AND TASK DEFINITION}

\subsection{Frozen Equipment-Domain Dataset}

We collected 400 public passages: 7 encyclopedia passages, 84 patent abstracts,
and 309 military- or equipment-related passages associated with CMNEE source
material \cite{zhu2024cmnee}. A project-recorded QAonMilitaryKG dictionary and
\modelname{Qwen2.5-14B-Instruct-AWQ} generated annotation suggestions, but no
machine output became gold without human review. Structural validation and
review produced dataset v1 with 30 support, 50 development, and 170 frozen test
passages; the other 150 candidates remain collection records.

The schema contains \entitytype{EQUIPMENT}, \entitytype{MODULE},
\entitytype{TECH\_SCHEME}, and \entitytype{METRIC}. The support split is the
only demonstration pool, development decisions preceded final evaluation, and
test labels are used only by the scorer. The public-text RAG corpus was
deduplicated against test texts with a fixed 8-gram overlap rule, preventing a
held-out query from reappearing as demonstration or retrieved evidence.
Supplementary Table S1 gives the entity definitions.

\subsection{Focused CLUENER Block}

CLUENER \cite{xu2020cluener} provides one additional Chinese NER schema. Its
official test file has no gold labels, so we evaluate all 1,343 labeled official
development rows (3,072 entity mentions across ten native classes). A separate
30-record support bank supplies demonstrations and a 61-entry support-derived
lexicon. The labels-stripped train-text RAG pool contains 9,584 rows after 89
fixed overlap removals; frozen retrieval selects three passages for each query.
Gold development labels enter only the scorer. No equipment-domain support,
glossary, or evidence passage is transferred into this block. Supplementary
Table S2 reports its class distribution.

\subsection{Evaluation and Human Calibration}

An entity is correct only when both span and type exactly match the reference.
We report entity-level micro precision, recall, F1, and false-positive (FP)
entity count. FP count measures extraction error, not open-domain factuality.

Two annotators independently labeled 20 previously unused non-test passages
from blank sheets under blinded identifiers. Their 175 and 220 annotations
contained 158 exact span-and-type matches, giving micro-F1 0.800000. Agreement
was strongest for \entitytype{METRIC} (1.000000) and weakest for
\entitytype{TECH\_SCHEME} (0.153846); Supplementary Table S3 contains all
per-type values. This audit checks whether the guideline can be applied by two
humans, but it is not formal frozen-test inter-annotator agreement.
