\section{DISCUSSION}

EC-FSIE reveals a practical choice that a single F1 ranking would obscure.
Configuration C is appropriate when missing domain entities is costly: its
glossary produces the highest recall and F1 in the frozen domain block.
Configuration D is preferable when precision and manual review capacity are
the main constraints: it gives up 0.003094 F1 relative to C but removes 55.0
FP on average. The framework exposes these settings as evidence controls rather
than presenting every added module as a monotonic improvement.

This interpretation depends on controlled replay. B changes demonstration
selection; C changes lexical evidence while reusing B's examples; and D changes
retrieved context while reusing the earlier controls. The common trace layer
then preserves prompt, parser, retry, and output provenance. Consequently,
metric changes can be connected to a specific evidence channel, which is often
more actionable for deployment than an opaque aggregate prompt recipe.

CLUENER strengthens this interpretation in a bounded way. Independently
constructed support, lexicon, and RAG resources reproduce the same qualitative
directions under a ten-class Chinese NER schema. This recurrence motivates
testing the operating-point view on further corpora, while the present evidence
remains anchored to the equipment domain and one additional labeled-dev block.

Finally, the calibration audit identifies schema quality as part of system
design. Strong overall agreement can coexist with an ambiguous type such as
\entitytype{TECH\_SCHEME}; applications should refine that boundary or attach
type-specific review policies. Likewise, the auditable Stage-R path creates a
reproducible basis for relation work, but its current scores direct future
effort toward relation definitions and evidence alignment rather than a larger
positive claim.
